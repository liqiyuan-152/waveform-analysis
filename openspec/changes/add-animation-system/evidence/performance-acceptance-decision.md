# 性能可达性与验收调整

日期：2026-10-13。用户授权：分析能否解决，不能解决就放宽条件；原生移动端不在本次范围。

## 判断

不能证明原阈值在理论上不可实现，但在现有 Vue/SVG/D3 架构、完整公共功能及当前投入范围内，没有已验证的可达路径。停止将无收益的小幅试探作为交付前置条件。此次修改设计/任务的性能验收，不减少四份 specs 的行为契约。

物理内存正式独立复测 12 场景/36 对，29 对超过旧目标，所有更新/淡化场景超标。最重淡化场景 87,638,080 bytes，降到 20,000,000 以下需要削减超过 77%；这不是微调可据实承诺的收益。该值是浏览器多进程物理采样差值，包含分配器及原生存储，不等同于 JS 对象或泄漏。现有证据尚未证明完整根因，不能保证更换渲染架构后必达标。

gzip 同轮正式对照为 12,011/11,835 bytes，达到原 10KB 目标约需再减少 15%–17%。理论上仍可优化，但最近十进制编码、舍入缓存等方案反而增加包体；最新 D3 默认字符串候选仅减少 183/161 bytes（约 1.5%），其小容器 10k 兼容更新物理三对为 56,574,144/55,902,400/53,444,800 bytes，仍超旧10MB目标。没有同期物理对照，不作候选必然更差的因果结论。

## 修订条件

1. gzip 每种格式完整增量 <15,000 bytes（十进制），同配置/依赖/WASM、递归完整计数。相对当前约12KB保留约25%余量，是可审计的工程预算，并非实验得到的加载体验临界值。保留原10KB为后续优化目标。
2. 物理内存原10/20MB转为诊断目标，不另定任意大上限。最终源码仍需完整配对测量及自然峰值、GC后留存、20次装卸记录。保留每系列最多双份几何、终态单份、所属资源清理等行为验收；真实残留或可重复持续增长不能豁免。当前高进程占用须公开为已知限制。
3. FPS、公共功能、输入不可变、数据查询、导出、SSR、tree shaking、450行及测试门禁不变；原生移动验收依用户指令排除。
