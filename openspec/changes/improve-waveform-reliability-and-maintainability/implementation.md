# 实施与验收记录

本阶段按用户授权实施代码，覆盖此前文档阶段的“仅创建文档”限制；分支为 `codex/plan-waveform-reliability-refactor`，未提交、推送、发布或归档。

## 实现

- 统一原始、占位、回退和 Worker 的视口连接点；可见统计独立，average/sum 不把边界原始点纳入桶。修复 WASM 数据集索引被重复偏移的问题。
- 调度器捕获任务拒绝后继续最新任务。注册和采样共享异常边界；Worker 请求异常经内部 request-error 返回并进入既有模式相关回退；取消和过期响应不产生新会话错误。会话统一管理请求、计时器、诊断、Worker 和资源释放。
- Node 22 / pnpm 10.32.1、450 物理行规则、lint:all、覆盖率和包消费门禁已同步。WASM prepare 校验 Rust 源码、Cargo 文件、构建配置、工具链、参数、环境及产物摘要；只有成功构建写记录，嵌套 prepack 复用校验后的产物，build:wasm 强制重建。
- 紧凑数组兼容层不再分配等长占位数组。内部几何、装饰点和最小可见点查询使用 WaveformPointSource；公开数组工具保持适配。已排序且有限的紧凑输入经过实际扫描验证后走复制快速路径，不重复构造索引数组或排序；未验证消息仍保留清洗与稳定排序路径。
- 拆出 useWaveformMeasurements、useWaveformViewportRestore、waveformSamplingSession。repository 保留数据集/缓存编排，其输入归一化和边界输出分别位于 repositoryDataset/outputBoundaries；useWaveformViewport 保留交互状态，数据替换恢复归新模块。所有 src 文本文件不超过 450 行，内部模块不加入 src/index.ts。
- 工作期间另一组未提交 niceScale 改动出现浮点域边界失败；保留其实现并仅修正返回域不包围输入的舍入误差，既有小数测试随最终全量检查通过。

## 缓冲区所有权

消费者数组 → 主线程私有归一化数值列 → toWorkerDataset 私有消息副本 → structured clone 后的 Worker 数据 → Worker 自有规范化列 → WASM 内存。没有使用 transfer，因此不 detach 消费者输入，也不释放回退所需消息数据。对象输入保留完整点/误差数据；紧凑消息只含采样需要的坐标，主线程源仍保留误差信息用于域和装饰。客户端缓存消息数据供 Worker 故障后重建 JavaScript repository，dispose 清空缓存和请求。

本轮保留这些有所有权意义的复制，只移除占位数组和重复排序/临时索引；不以信任消息标记绕过外部输入验证。

## 浏览器验证

1280×800 窗口，组件容器 1000px/360px；WASM Demo 桌面和 360px 外层容器（内部图表 340px，浏览器窗口最小宽度 500px）。保存 evidence/browser-final.json、browser-boundaries.json、browser-presentation.json 与截图。

- 正常 auto 使用真实 Worker/WASM；Worker 抛错和 WASM fetch 拒绝分别注入。
- auto/javascript、wasm/javascript 使用 JavaScript，wasm/error 报 unavailable/fallback none 并保留路径；raw 不创建 Worker。

- 无内部点的线性和四类阶梯线均保留跨视口路径；分页从 s0/s1 到 s2/s3，再返回；图例隐藏同步隐藏注解，恢复后注解重新显示；共享与独立视口在数据引用替换后仍为约 [2,8] 秒（浮点误差量级 1e-15）。
