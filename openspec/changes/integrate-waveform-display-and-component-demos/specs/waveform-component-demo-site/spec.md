## ADDED Requirements

### Requirement: 统一组件示例站点

Demo SHALL 按波形分析和波形展示组织导航，保留两边现有场景及控制面板，并为示例提供说明、运行视图、API 说明及对应使用代码；旧分析 URL SHALL 保持可访问。

#### Scenario: 切换组件示例
- **WHEN** 用户在两个组件分组间切换或打开旧分析链接
- **THEN** 对应示例和控制面板可用，展示场景的迁移位置有明确映射

### Requirement: Demo 基础能力和依赖统一

Demo SHALL 共用适用的布局、控件和数据生成能力，统一 UI 依赖版本，并消费构建包公开入口；库运行时不得依赖 Demo UI 库。

#### Scenario: 独立构建站点
- **WHEN** 从当前仓库构建并部署 Demo
- **THEN** 一次构建提供两个组件示例，不引用同级项目或库内部源码，控件保持可用

### Requirement: 示例代码与运行实现一致

Demo SHALL 从同一可运行示例源展示代码或通过自动校验保持两者一致，示例仅使用正式公开入口，明确原生类和 Vue 组件的不同用法。

#### Scenario: 复制示例代码
- **WHEN** 用户复制组件示例代码到具备声明依赖的独立消费项目
- **THEN** 代码可进行类型检查并运行，无内部路径、遗漏样式或未实现导出

### Requirement: 同页动画与响应式验收

Demo SHALL 提供双组件同页动画示例，通过各组件已有公共 API 提供适用的独立动画控制、替换数据和卸载，明确能力差异：分析图表实例没有直接 pause/resume 时仅展示现有开关/更新控制，展示使用其公开 animation 接口，不为 Demo 暴露内部动画类，并验证组件消费页及 Demo 的桌面、小容器和小视口行为。

#### Scenario: 同页操作与窄容器
- **WHEN** 用户在桌面及小尺寸下操作一个组件的动画和生命周期
- **THEN** 另一个组件不受影响，图形及控制面板可使用，无样式或 SVG ID 冲突，并留存浏览器验证证据

### Requirement: 示例路由加载与资源释放

Demo SHALL 按组件页面懒加载，并在离开页面时释放该页图表、监听与动画任务；不能以统一站点为由要求首屏加载全部组件。

#### Scenario: 反复切换组件示例
- **WHEN** 用户反复进入和离开两个组件示例及同页共存页
- **THEN** 原页面不留下 SVG 和活动动画任务，监听不持续累积，新页面图表可正常交互
