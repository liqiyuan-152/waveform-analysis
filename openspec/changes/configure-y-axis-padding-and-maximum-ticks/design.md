## Decisions

### 1. API 与默认值

在 WaveformAxesOptions.y 保留 upperPaddingRatio，新增 upperPaddingEnabled、lowerPaddingEnabled、lowerPaddingRatio。两侧对称解析：

| 开关 | 比例 | 有效比例 |
| --- | --- | --- |
| false | 任意 | 0 |
| true | 未提供 | 0.1 |
| true 或未提供 | 有限正数 | 指定值 |
| 未提供 | 未提供 | 0 |
| true 或未提供 | 0、负数、NaN、Infinity | 0 |

不修改旧 upperPaddingRatio 默认 0 的含义，不要求旧消费者补开关。避免仅依赖比例控制，因为用户需要关闭时保留此前比例。新增字段沿用已有导出类型，不增加无必要的顶层 API。

### 2. 范围与生命周期

令 [a,b] 为轴组自动数据范围在常量回退之后、比例留白和 nice 之前的范围，s=b-a。一次计算 [a-s*lowerRatio,b+s*upperRatio]，不能将第一侧扩展后的跨度用于另一侧。数值非有限时，对应侧退回原边界，不输出 Infinity。

固定轴组不扩展；组内混合固定与自动系列时，沿用既有 fixed 判定。手动 Y 视口优先，缩放和平移不重复加留白；reset/fit 清理手动 Y 视口后重新计算。修改开关不清除手动视口。nice 在留白后执行，可能进一步扩域；关闭某侧仅关闭比例规则，不禁止 nice 扩域。不在本变更中替换最终整合基线采用的 nice 算法。

单 Y 轴按组内系列合并范围，多 Y 轴按各轴组范围；独立、分离、紧凑模式使用同一规则。开启误差棒时范围含误差端点；隐藏、分页和数据更换遵循既有系列选择规则。计算基于完整数据，不基于采样 SVG。常量按现有 5% / 零值回退展开后计算跨度；空轴不凭空产生最大值刻度。输入数据及缓存中的原始域不可被留白结果覆盖。

### 3. 最大值的定义及可见条件

最大值 M 是参与当前轴组范围计算的完整数据上限；误差棒参与范围时包含其上端点。M 在常量回退、留白、nice 前保存，因此常量 5 的标记仍为 5，而不是回退后的上限。

当上方有效比例大于 0、轴组非固定且存在数据时生成 M 的特殊刻度。手动视口不重新留白，但 M 位于当前最终 Y 域内时仍保留标记，域外不显示、不夹到边框。只有下方开启不生成特殊最大值刻度。该定义延续既有自动范围语义，不引入单独的纯中心线极值 API。

例如原始范围 [0,100]、上方 10%、nice=false，显示 100 的刻度及标签，同时保留不冲突的 110 上限刻度。多轴分别标记，不用一个全局最大值替代各轴最大值。紧凑模式原有边界标签抑制不能提前丢弃特殊最大值标记。

### 4. 最大值优先的像素避让

先保留正常刻度结果，再插入或合并特殊 M，不修改刻度数请求本身的公共语义；显示数量可因特殊标记和避让增减。数值相等按相对浮点容差判断，不能仅因格式化文本相同就合并不同数值。M 使用轴的既有单位和格式化规则。

先投影到实际 SVG 像素，再按文字真实包围盒进行避让：普通标签与最大值标签垂直间距不足 4px 且横向范围相交时隐藏普通标签。无法测量时使用字体度量回退，并在字体就绪后重算。只有标签冲突时保留普通短刻度；线条中心距小于两者描边半宽之和再加 1px 时，隐藏普通短刻度及其关联水平主/次网格线，避免叠加变粗。M 与既有数值相等则仅绘制一次，不残留重复网格线。

与轴上限冲突时隐藏普通上限标签，图框边框始终保留；与边框同位置的线复用边界，不再叠加水平线。最大值标记不新增贯穿全图的强制参考线，沿用现有网格开关和样式。多轴各自处理标签冲突，仅处理实际关联的网格，不能凭空为无网格的轴新增网格。

标签保持真实 Y 坐标，不上下搬移、不扩大数据域。需计入最大值文字宽度以更新轴槽位及左右留白；边界处预留必要文字布局空间。不同轨道轴标签确有碰撞时执行同一优先级；两个特殊最大值标签冲突时保留两者，不擅自隐藏真实最大值，记录极小容器限制。

### 5. 实现边界

最小扩展已存在的 resolveRenderedYAxisSeriesGroups；可提取内部 yAxisPadding 小模块解析配置，避免为上下两侧复制链路。绘制、轴文字测量和轴槽位共享结果，避免各自添加留白。最大值元信息需独立于常量回退域保存，普通刻度与特殊刻度分别保留标签/线可见性，不直接删改公共数据范围。

预计涉及 src/types/chart.ts、src/components/core/layout.ts、trackLayoutBuilder.ts、useWaveformLayout.ts、useWaveformYAxisLayout.ts、yAxisLayoutMetrics.ts、内部布局类型、WaveformTrackAxes.vue、WaveformTrackBackdrop.vue，以及必要的数据极值元信息。按整合后的职责拆分落地，所有 src 文件不超过 450 物理行。

Demo 配置区新增上下开关与百分比输入，两个开关默认显式开启，初始比例 10%；关闭后禁用输入但保留数值。组件省略配置仍默认不留白。说明固定范围不生效、nice 可增加额外留白，不放入图内工具栏。README 提供如下宿主接入，宿主不自行扩域：

```ts
y: {
  lineVisible: false,
  nice: false,
  upperPaddingEnabled: true,
  lowerPaddingEnabled: true,
  upperPaddingRatio: 0.1,
  lowerPaddingRatio: 0.1,
}
```

## Risks / Trade-offs

- 旧工作区覆盖新版能力 → 先做三方行为清单和未提交内容保护；冲突优先保留 2026-10-11 修改，保留新版 upperPaddingRatio 兼容测试。
- 常量回退掩盖真实最大值 → 单独保留原始上限元信息，增加常量和误差棒用例。
- 标签测量反馈造成抖动 → 稳定原始候选刻度和确定性优先级，尺寸/字体变化后重算，避免把已过滤结果作为下次输入。
- 避让隐藏普通刻度改变视觉密度 → 最大值优先规则明确，不改变比例尺与事件数值。
- 极小图框容不下多个特殊标签 → 保留真实最大值、不伪造位置；浏览器报告实际限制。
