# 设计

## 分层和所有权

src/shared/axis/AxisView 是唯一通用轴绘制类，接受渲染计划，无组件名称分支。
分析 view/AxisView 负责持久分组与装饰，并为每个分组持有共享 view。
展示 renderer/axes 在现有 BaseView 重绘与 DOM 协调流程中使用同一个共享类；本任务不重写展示生命周期。
共享模块不依赖 analysis/display、框架、全局实例或公开入口；缓存按 SVG 分组保存，销毁后可回收。

## 策略边界

| 能力 | 共享 | 保留在适配层 |
| --- | --- | --- |
| 绘制 | 四方向、D3 生成器、增量属性更新 | 分组位置、样式、标题和端点 |
| 刻度 | 125/1235 系数、固定端点感知的范围扩展 | 密度、上限、精度、极值回退、是否扩展视口 |
| 测量 | 后端调用、不可测时回退、释放 | canvas/SVG、字体、回退字宽 |
| 动画 | domain 改变时更新刻度位置 | 各组件现有时间线及布局调度 |

分析 X 原始值仍为秒，格式器只改变文本。分析 X 不扩展视口、上限 3000；
展示保留上限 100 和亚正常数回退。Y 保留各自常量范围与固定边界语义。

## 更新正确性

ticks 引用稳定、方向和生成器几何不变时，更新已有刻度坐标及变化的文本；
相同帧不产生 SVG 属性或文本变更。range、方向、tickSize、outerSize、padding、offset
变化触发重新生成。方向变化清除旧方向刻度几何并更新锚点。
轴线支持 visible/hidden/none；从删除状态恢复时重新生成 domain path。
调用方生成新的 ticks 数组表示刻度变化，不支持原地修改缓存数组。

## 风险与验证

文字测量的字体和近似公式不变；无法测量、抛异常、非有限/非正宽度统一使用回退。
共享测量类不在导入时访问 DOM，分析仍延迟创建所属 document 的 canvas。
验证已有两组件刻度、动画、布局与测量测试，并新增核心缓存、方向切换、轴线恢复回归；
运行全量覆盖率、边界、构建、独立包消费，以及桌面/窄视口 Demo 浏览器验收。
证据独立写入本 change 的 evidence，不覆盖前一集成任务的截图。
