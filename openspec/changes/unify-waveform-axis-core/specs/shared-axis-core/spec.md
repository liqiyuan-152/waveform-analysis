## ADDED Requirements

### Requirement: 共享轴绘制机制

两组件的 X/Y 轴 SHALL 使用同一内部轴绘制核心，通过方向和渲染计划配置，保留组件装饰适配层，不新增公开轴类。

#### Scenario: 分析与展示同时运行
- **WHEN** 同页渲染两个组件并更新任一组件
- **THEN** 两者使用共享实现，状态、布局、单位和生命周期互不干扰

### Requirement: 保留数值和布局策略

系统 SHALL 共享 nice 系数、边界扩展与文字测量机制，并保留各组件的密度、精度、极值回退、固定边界及标签策略。

#### Scenario: 格式与范围兼容
- **WHEN** 使用分析秒坐标、展示科学计数法或固定/反向 Y 范围
- **THEN** 原始坐标与事件值不被格式化修改，范围和标签继续遵循各自既有规则

### Requirement: 正确增量更新

共享核心 SHALL 保留域动画的现有刻度节点，在相同输出时避免 DOM 变更，并正确处理几何变化及轴线恢复。

#### Scenario: 更新方向和尺寸
- **WHEN** 方向、range、刻度尺寸或间距发生变化
- **THEN** 轴几何更新且不残留旧方向属性

#### Scenario: 恢复轴线
- **WHEN** 删除轴线后设置隐藏或显示轴线
- **THEN** domain path 重新生成且可见性正确
