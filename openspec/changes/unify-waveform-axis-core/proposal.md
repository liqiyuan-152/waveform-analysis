# 统一波形坐标轴核心

## Why

波形分析与波形展示已经在同一包中，坐标轴仍重复创建 D3 轴、选择数值步长和处理文字测量。
直接统一所有刻度规则会改变秒坐标、视口边界和展示格式。需要统一机制，同时保留组件策略。

## What Changes

- 使用一个内部 AxisView，以方向、scale、ticks、formatter、尺寸和轴线可见性组成渲染计划。
- 共享 SVG 增量更新、nice 系数、可选边界扩展及带后端和回退策略的文字测量。
- 分析适配层保留单位、端点、紧凑标签和标题；展示适配层保留科学计数法、多行文本和碰撞处理。
- 不增加公开导出，不改变输入、事件、动画 API 或默认刻度密度。

## Impact

影响两个原生组件的轴绘制及布局测量。现有 Vue 适配器通过分析组件使用共享核心。
兼容路径 components/rendering/updateAxis 保留重导出；旧集成任务及其证据不被替换。
